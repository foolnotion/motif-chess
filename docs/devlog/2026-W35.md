# Week 35 - 2026-08-24

## Decisions

- **[D050] Adopt Slint for the production desktop presentation layer.** A
  real-database spike remained responsive with 500 game rows and games from 20
  through 300 plies, including through waypipe's software-rendered path. New UI
  work will use toolkit-neutral presenters behind a narrow Slint adapter. The
  working Qt application remains until vertical slices reach parity. Rejected:
  extending Qt Quick/KDDockWidgets for new presentation work, a big-bang
  rewrite, reproducing arbitrary docking, and promoting the synchronous spike
  directly into the production shell.

## Learned

- Slint's table interactions and long-game navigation remain responsive under
  software rendering and display forwarding, which resolves the spike's main
  usability risk.
- Winit loads some Linux window libraries dynamically; the Slint package must
  expose them through RPATH rather than relying on `LD_LIBRARY_PATH`.
- Upstream vcpkg has no Slint port, so Linux can proceed while Windows remains
  an explicit packaging blocker.

## Done

- Built and tested a parallel Slint game-browser target without introducing
  Slint types into backend modules.
- Validated 500 games split across 20-, 80-, 160-, and 300-ply lengths.
- Published the Slint runtime RPATH fix in the foolnotion overlay.
- Defined the production migration contract in `spec-008`.

## Problems and Solutions

- **Problem:** The initial winit executable required an ad hoc runtime library
  path. **Solution:** Add the dynamically loaded Wayland, X11, input, and OpenGL
  libraries to the Linux package RPATH.
- **Problem:** The current canonical GUI spec describes completed Qt work and
  cannot safely serve as the migration contract. **Solution:** Preserve
  `spec-004` as history and create `spec-008` for incremental Slint parity.

## Open Questions

- Which approved packaging route should provide Slint to Windows through the
  vcpkg workflow?
- What exact responsive workspace arrangement should replace docked and
  floating panels at narrow and wide window sizes?
